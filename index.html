About

I'm a front-end developer who came to web development through an unconventional path -- a background in hospitality management, followed by hands-on SEO and web performance work that pulled me straight into code. That experience shaped how I build: I don't just make things look good, I care about how fast they load, how well they rank, and whether real users can actually use them.

My foundation is HTML, CSS, and JavaScript, and I build with an eye for performance and structure -- semantic markup, optimized assets, and interfaces that hold up under real-world use. I've shipped multiple responsive, multi-page sites from scratch, including a live client project, handling everything from layout and interactivity to Core Web Vitals and SEO fundamentals.

Right now, I'm deepening my JavaScript skills -- moving from vanilla DOM manipulation into more structured, scalable patterns -- and adding Python to start building real backends, so I can take my projects from static front-ends to fully functional full-stack applications over the next few months. If you're looking at this portfolio a little later than today, expect to see that shift already in progress.
